# Contributing

Thanks for helping improve this node.

## Prerequisites

- Node.js `^22.21.0 || >=24.0.0`
- npm
- n8n knowledge for manual validation workflows

## Local Setup

```bash
npm ci
```

## Development Commands

Use the scripts from `package.json`:

```bash
npm run dev
npm run lint
npm run lint:fix
npm run build
```

Notes:

- `npm run dev` uses `n8n-node dev` for local node development.
- `npm run build` compiles distributable files into `dist`.
- `npm run lint` runs the n8n/ESLint checks used in CI.

## Manual Validation Template

Use [examples/test-template.svg](./examples/test-template.svg) as the canonical test fixture when validating changes.

Suggested validation scope:

- Insert Text on `target-text` and `target-tspan`.
- Insert Image on `target-rect`, `target-circle`, `target-ellipse`, `target-path`, `target-polygon`, `target-polyline`, and `target-line`.
- Confirm output SVG renders as expected and no operation-specific errors are raised.

## Pull Requests

- Keep changes focused and include documentation updates when behavior changes.
- Verify lint and build locally before opening a PR.
- Include reproducible steps for behavior changes.

## Commit Messages and Versioning

This repository uses release automation based on commit history.

- Conventional Commit style is recommended because it improves automatic version calculation and changelog quality.
- Non-conventional commit messages are not intended to block CI.
- `CHANGELOG.md` is generated by release automation and should not be edited manually.

## Security and Sensitive Data

- Do not commit secrets, credentials, or private keys.
- This node does not require runtime credentials.
